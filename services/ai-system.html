Training AI System Design

AI System Design & MLOps Foundations

เรียนรู้การออกแบบระบบ AI ตั้งแต่การเตรียมข้อมูล การสร้างโมเดล การนำโมเดลขึ้นใช้งานจริง และการติดตามประสิทธิภาพของระบบ เพื่อพัฒนา AI ที่พร้อมใช้งานในสภาพแวดล้อมจริง

เกี่ยวกับหลักสูตร

หลักสูตรนี้เหมาะสำหรับผู้ที่ต้องการเข้าใจภาพรวมของระบบ AI ตั้งแต่ต้นทางจนถึงการใช้งานจริง ครอบคลุม Data Pipeline, Model Training, Deployment, Monitoring และแนวคิดพื้นฐานของ MLOps เพื่อให้สามารถออกแบบระบบที่มีประสิทธิภาพและดูแลต่อได้ง่าย

สิ่งที่จะได้เรียนรู้

  • ✓พื้นฐานการออกแบบ AI System Architecture
  • ✓การออกแบบและจัดการ Data Pipeline
  • ✓ขั้นตอนการ Training และจัดการ AI Model
  • ✓การ Deploy Model สำหรับการใช้งานจริง
  • ✓การติดตามประสิทธิภาพและความเสถียรของระบบ
  • ✓แนวคิดพื้นฐานของ MLOps Workflow

เนื้อหาหลักสูตร

Module 1 — AI System Architecture

ทำความเข้าใจองค์ประกอบของระบบ AI และการออกแบบ Architecture เบื้องต้น

Module 2 — Data Pipeline & Model Training

เรียนรู้ขั้นตอนการรวบรวม เตรียมข้อมูล และจัดการกระบวนการ Training Model

Module 3 — Model Deployment

เรียนรู้แนวทางการนำ AI Model ขึ้นใช้งานและเชื่อมต่อเข้ากับระบบจริง

Module 4 — Monitoring & MLOps

ติดตามประสิทธิภาพของ Model และทำความเข้าใจ Workflow พื้นฐานของ MLOps

ผลลัพธ์หลังเรียนจบ

ผู้เรียนจะเข้าใจภาพรวมของการพัฒนาระบบ AI ตั้งแต่ข้อมูล การสร้างโมเดล ไปจนถึง Deployment และ Monitoring และสามารถนำแนวคิด MLOps ไปใช้ในการออกแบบระบบจริงได้
